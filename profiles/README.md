# Profiles

The default profile lives with the package that loads it: [`packages/profile/default.yaml`](../packages/profile/default.yaml). It is published with `@concordance-wiki/profile` and validated by [`profile.schema.json`](../packages/core/schemas/profile.schema.json).

A project profile (`profile.yaml`) is merged on top of it key by key; see [writing notes](../docs/guides/writing-notes.md#profile).
