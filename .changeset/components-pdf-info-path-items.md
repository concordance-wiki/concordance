The union-find of the duplicate resolution finds the root of a component by a loop with path compression, so that thousands of resources merged in a chain cost no stack; the PDF reader takes the last Info object when an update rewrote it under the same number; the OpenAPI reader follows a path item given as a local `$ref` and lists under `unresolvedPaths` those it cannot follow, instead of dropping the path in silence.
