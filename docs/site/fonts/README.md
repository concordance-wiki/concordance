# Fonts

The three typefaces of the home page, self-hosted so that a visit calls no third party: Instrument Sans (variable, 400 to 700, upright and italic), Instrument Serif (regular and italic) and IBM Plex Mono (400, 500, 600). Latin and Latin Extended subsets only, as woff2.

All three are published under the SIL Open Font License 1.1: Instrument Sans and Instrument Serif by the Instrument Sans and Instrument Serif project authors, IBM Plex Mono by IBM. The licence text is in `OFL.txt`.
