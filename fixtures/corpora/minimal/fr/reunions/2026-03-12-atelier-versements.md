# Atelier versements

Participant-1 a distingué le versement programmé, le versement libre et le versement exceptionnel, qui sort du cadre contractuel. Participant-3 a demandé où vit le plafond annuel ; Participant-2 a répondu : côté serveur uniquement, dans l'API Versements. Voir [plafond contrôlé côté serveur](../decisions/plafond-controle-cote-serveur.md).

Le versement exceptionnel ne passe pas par le plafond annuel ; il est validé par le responsable d'agence.
