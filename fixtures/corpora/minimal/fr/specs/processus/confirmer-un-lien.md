# Confirmer un lien

## Étapes

1. Le [mainteneur](../roles/mainteneur.md) ouvre l'entité sur [page entité](../ecrans/page-entite.md).
2. Le mainteneur valide le lien sur [panneau des mentions](../ecrans/panneau-des-mentions.md).
   - Si le [plafond du lien connexe](../regles/plafond-du-lien-connexe.regle.md) est dépassé, aller à l'étape 4.
3. L'[API Requête de modèle](../api/requete-de-modele.md) enregistre le lien.
4. Fin.
