# Confirm a link

## Steps

1. The [maintainer](../roles/maintainer.md) opens the entity on [entity page](../screens/entity-page.md).
2. The maintainer confirms the link on [mentions panel](../screens/mentions-panel.md).
   - If the [related link cap](../rules/related-link-cap.rule.md) is exceeded, go to step 4.
3. The [Model query API](../api/model-query.md) records the link.
4. End.
