# Atelier versements

Participant-1 a distingué le versement programmé, le versement libre et la cotisation. Participant-3 a demandé où vit le plafond annuel ; Participant-2 a répondu : côté serveur uniquement, dans l'API Versements. Voir [plafond contrôlé côté serveur](../decisions/plafond-controle-cote-serveur.md).

Les agences saisissent les versements libres sur l'écran Saisie de versement libre ; le [règlement nocturne](specs:batchs/reglement-nocturne.md) fixe la date de valeur le lendemain matin.
