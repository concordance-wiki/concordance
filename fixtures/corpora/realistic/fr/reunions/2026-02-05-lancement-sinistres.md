# Lancement sinistres

Participant-1 a présenté le parcours sinistre : déclaration en agence, instruction par le gestionnaire sinistres, indemnité nette de franchise. Participant-4 a demandé si le délai de carence s'applique à un sinistre déclaré le premier mois d'une garantie ; Participant-2 a répondu que le délai de carence est défini par garantie dans les conditions particulières et n'est pas contrôlé par l'API Sinistres aujourd'hui.

Participant-2 a proposé d'étendre le délai de déclaration à dix jours ouvrés : voir [délai de sinistre étendu](../decisions/delai-sinistre-etendu.md). Participant-1 documentera le délai de carence dans le cadrage sinistres.
