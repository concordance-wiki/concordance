# Lien explicite

Un lien markdown qu'un auteur a écrit d'une note vers une autre, dans la même source ou, avec le préfixe `source:` ou une remontée relative, dans une source voisine. Sa confiance est de 1,0 et sa relation est affinée par la section où il se trouve.
