# Seuil appliqué dans le modèle

Le seuil de publication s'applique une fois, à l'écriture du modèle canonique. Les pages affichent les comptes du modèle et ne recomptent jamais une occurrence. Décidé lors de la [revue du seuil de page mot-clé](../reunions/2026-03-12-revue-du-seuil-de-page-mot-cle.md).
