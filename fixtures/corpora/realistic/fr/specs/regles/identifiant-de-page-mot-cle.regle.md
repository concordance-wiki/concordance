# Identifiant de page mot-clé

Une page mot-clé est identifiée par `keywords/` suivi du slug de son expression ; deux expressions qui se replient sur le même slug partagent une page. Le [seuil de publication](seuil-de-publication.regle.md) se compte sur la page, pas sur chaque graphie.
