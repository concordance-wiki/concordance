# Délai de déclaration du sinistre

Une déclaration de sinistre doit parvenir à l'assureur dans les dix jours ouvrés suivant l'événement, délai porté de cinq à dix par [délai de sinistre étendu](../../decisions/delai-sinistre-etendu.md). Une déclaration tardive est refusée sauf si le responsable d'agence lève le délai.
