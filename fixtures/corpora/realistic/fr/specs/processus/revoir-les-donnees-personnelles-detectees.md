# Revoir les données personnelles détectées

Un build signale un passage qui ressemble à des données personnelles.

## Étapes

1. Le build lève un constat sur le passage.
2. Le [mainteneur](../roles/mainteneur.md) le revoit sur [page à faire](../ecrans/page-a-faire.md).
   - Si le passage est un faux positif, aller à l'étape 4.
3. L'[auteur](../roles/auteur.md) pseudonymise le passage ou exclut le fichier.
4. Fin.
