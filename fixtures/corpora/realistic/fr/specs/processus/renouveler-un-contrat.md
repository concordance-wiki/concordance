# Renouveler un contrat

Un contrat arrive à son échéance.

## Étapes

1. Le batch d'[appel de cotisation](../batchs/appel-de-cotisation.md) envoie l'avis de renouvellement selon la règle de [préavis de renouvellement](../regles/preavis-de-renouvellement.regle.md).
2. L'adhérent donne congé ou reste silencieux.
   - Si congé est donné, aller à [résilier un contrat](resilier-un-contrat.md).
3. Le contrat est renouvelé avec le nouveau taux de cotisation.
4. Fin.
