# Cadrage vie privée

Note de cadrage du périmètre des données personnelles : transcriptions pseudonymisées avant publication, données personnelles détectées revues à la main, une liste `privacy.exclude` qui retire des fichiers avant toute lecture. Les ressources jumelles sont appariées après la pseudonymisation, jamais avant.

Le processus [revoir les données personnelles détectées](../specs/processus/revoir-les-donnees-personnelles-detectees.md) est le seul chemin pour un passage signalé ; la [visionneuse de document](../specs/ecrans/service/visionneuse-de-document.md) ne sert jamais un binaire d'origine.
