# Non-objectifs

Ce que la première version ne fait pas : pas de résumé de build publié sur la forge, pas de reconstruction incrémentale, pas d'édition en direct, pas de service hébergé, aucun binaire servi depuis le site.

L'[API Modèle canonique](../specs/api/modele-canonique.md) est le seul export d'un build ; la [page à faire](../specs/ecrans/page-a-faire.md) est le seul endroit où un constat est acquitté.
