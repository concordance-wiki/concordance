# Cadrage sinistres

Note de cadrage du périmètre sinistres : déclaration en agence, instruction par le gestionnaire sinistres avec un expert, indemnité nette de franchise, provision mise à jour chaque jour ouvré. Le délai de carence de chaque garantie est appliqué à la main pour l'instant.

L'[API Sinistres](../specs/api/sinistres.md) est un service SOAP historique ; l'écran d'[instruction du sinistre](../specs/ecrans/instruction-sinistre.md) travaille directement sur le dossier sinistre.
