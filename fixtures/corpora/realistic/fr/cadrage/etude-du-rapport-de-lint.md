# Étude du rapport de lint

Dimensionne la publication du résumé de build sur la forge. Aujourd'hui le résumé de build est assemblé à la main à partir du journal de build par le responsable qualité ; demain l'[API Pont de forge](../specs/api/pont-de-forge.md) le transmet et la demande de fusion montre le résumé de build en ligne.

Le changement touche [lint dans une demande de fusion](../specs/processus/lint-dans-une-demande-de-fusion.md), la règle [politique fail-on](../specs/regles/politique-fail-on.regle.md) et la [page à faire](../specs/ecrans/page-a-faire.md).
