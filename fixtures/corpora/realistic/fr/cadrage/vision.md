# Vision

Concordance transforme les notes markdown de plusieurs dépôts en un seul site statique : chaque note devient une page d'entité, chaque expression récurrente une page mot-clé, chaque doute un constat. Toute règle vit dans le build ; le site est un rendu, jamais une seconde implémentation.

Cette note ne déclare aucune application à dessein : la ligne de commande et le service sont décrits par leurs spécifications et par la [revue du périmètre du service](../reunions/2026-04-02-revue-du-perimetre-du-service.md).
