# Realistic corpus

A few hundred fictional files about a generic personal insurer: notes of every implemented type, framing documents, slide decks, transcripts with `Speaker 1` and `Speaker 2`, duplicates across formats, and deliberate errors for every check. Built in English and French by the golden corpus story; `expected/` holds the model and findings the engine must produce.

Empty until then. The `minimal` corpus is the reference in the meantime.
