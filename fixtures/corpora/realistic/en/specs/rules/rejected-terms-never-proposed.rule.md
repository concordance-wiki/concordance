# Rejected terms never proposed

An expression rejected in the lock file is never proposed again, neither as a keyword page nor as a suggestion, whatever its occurrences. Removing it from the lock file is the only way back.

## Applies to

- [Keyword page](../screens/keyword-page.md)
- [Suggestion review](../screens/service/suggestion-review.md)
- [Candidate](../objects/candidate.md)
