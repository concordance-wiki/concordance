# Cross-source links off

A link that leaves its source is reported and ignored unless the configuration enables cross-source links. This corpus enables them: the meetings link to the specs with the `specs:` prefix.

- [Entity page](../screens/entity-page.md)
- [Mentions panel](../screens/mentions-panel.md)
