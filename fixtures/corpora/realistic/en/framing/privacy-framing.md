# Privacy framing

Framing note for the personal data scope: transcripts pseudonymised before publication, detected personal data reviewed by hand, a `privacy.exclude` list that removes files before anything is read. Twin resources are paired after pseudonymisation, never before.

The [review detected personal data](../specs/processes/review-detected-personal-data.md) process is the only path for a flagged passage; the [document viewer](../specs/screens/service/document-viewer.md) never serves an original binary.
