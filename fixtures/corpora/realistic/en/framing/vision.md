# Vision

Concordance turns the markdown notes of several repositories into one static site: every note becomes an entity page, every recurring expression a keyword page, every doubt a finding. Every rule lives in the build; the site is a rendering, never a second implementation.

This note declares no application on purpose: the command line and the service are described by their specifications and by the [service scope review](../meetings/2026-04-02-service-scope-review.md).
