# Lint report study

Sizes the posting of the build summary to the forge. Today the build summary is assembled by hand from the build log by the quality owner; tomorrow the [Forge bridge API](../specs/api/forge-bridge.md) hands it over and the merge request shows the build summary inline.

The change touches [lint in a merge request](../specs/processes/lint-in-merge-request.md), the [fail-on policy](../specs/rules/fail-on-policy.rule.md) rule and the [to-do page](../specs/screens/to-do-page.md).
