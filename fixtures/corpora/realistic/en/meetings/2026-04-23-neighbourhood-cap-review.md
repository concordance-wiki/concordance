# Neighbourhood cap review

Participant-3 showed that a related link born from a single co-occurrence can outrank an explicit link on the neighbourhood map, which authors dislike. Participant-1 proposed to cap related at 0.6, applied in the Canonical model API like the publication threshold: see [related relation capped](../decisions/related-relation-capped.md).

The screen Neighbourhood map and the service's Pinned trail display the capped confidence without change.
