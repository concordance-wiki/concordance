# @concordance-wiki/core

Model types, identifiers, canonical sorting, deterministic utilities and the plugin API. Ships the JSON schemas under `schemas/`.

Today: configuration parsing and validation (`parseConfig`, `validateConfig`, `formatValidation`), the schema reader (`readSchema`) and error describer (`describeSchemaError`) and the injected file system (`FileSystem`, `nodeFileSystem`, `memoryFileSystem`).

Part of [Concordance](../../README.md).
